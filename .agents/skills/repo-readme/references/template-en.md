# English outline

Use the repository README as the current example, not a copied template.

| Section | Reader outcome |
| --- | --- |
| Header, description, demo | Understand what zlib does, where data lives, and see the interface |
| Install | Copy the command for their platform or choose a release binary |
| Quick start | Find a reachable domain, log in, open the TUI, and run a first search |
| Terminal interface | Know the keys for a first session and where the full list is |
| Commands | Run a table or JSON search and discover a few common tasks |
| Agent setup | Install the Claude Code or Codex plugin after CLI login, or register `zlib mcp` |
| Documentation | Reach the guide for configuration, troubleshooting, or advanced use |

Keep public anchors such as `#quick-start`, `#terminal-interface`, and
`#agent-setup`. If one changes, update inbound links. Required prerequisites
belong next to the command. Label example domains and book references as values
to replace.
