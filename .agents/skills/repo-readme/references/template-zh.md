# 中文编写要点

以仓库当前 README 为示例，不维护另一份完整正文。

| 英文章节 | 中文章节 | 读者完成的操作 |
| --- | --- | --- |
| Install | 安装 | 复制对应平台的安装命令 |
| Quick start | 快速开始 | 检测域名、登录、进入 TUI 并搜索 |
| Commands | 常用命令 | 使用表格或 JSON 搜索，找到常用操作 |
| Agent setup | Agent 接入 | 登录 CLI 后安装 Claude Code 或 Codex 插件 |
| Documentation | 文档 | 找到配置、排障和详细用法 |

中英文代码块保持一致。命令名、参数、路径、JSON 字段和插件名称使用原文。
说明按中文习惯表达，例如“按 Enter 搜索”“选择下载目录”“先列出结果”。
域名示例要说明如何替换，下载确认和实际下载要写清楚。
保留已有章节锚点；改名时检查其他文档的链接。
