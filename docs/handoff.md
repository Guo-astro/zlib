## What the working branch changes

### Transport: EAPI only

`aa7ec45` migrates the client to the JSON EAPI and removes the scraped-HTML transport. Gone from the code: `parser.go`, the JS proof-of-work solver and `Client.get()` retry loop, the anti-scraping download-URL extraction, `loginEAPIViaHTML`, and the MCP server. Several older notes (the previous version of this file, and any session that predates `aa7ec45`) describe those pieces as live; they are not.

What stays for compatibility only: `ClientMode`/`SetMode` (always `ClientModeEAPI`), the session's `"mode"` field, and the hidden no-op flags `login --eapi` and `doctor --eapi`. `isChallengePage` survives solely so `doctor` can classify a challenged mirror as usable.

Security-relevant behaviour that did carry over: the mirror allowlist (`domain_policy.go`), allowlist re-validation after redirects (`resolveEAPIDomain`, `stripEAPICredentialsOffAllowlist`), and the narrow DiamWall detector (`isBotProtectionResponse`).

### Terminal UI

`ee6aea4`, `4679876` and `8c283c8` build a persistent shell (`zlib tui`): `/`-prefixed command dispatch, a command palette, shared list/card rendering (`book_feed_view.go`), a Search filter form that maps 1:1 to `SearchOptions` and the `search` flags, theme picker plus custom-theme editor, and standalone `kindle`/`profile` commands that reuse shell pages.

### New commands

`favorites`, `recommended`, `most-popular`, `config` (`network`/`download`/`kindle` subcommands), `update`, `theme`, `tui`, and `history --delete`. `ZLIB_DOWNLOAD_DIR` sets the default download directory (`b2d816c`).

### Agent plugins

Skills are authored in `.agents/skills/`; `plugins/zlib/skills/` is generated by `scripts/sync-plugin-skills.mjs` and CI runs it with `--check`. A Codex marketplace was added next to the Claude one. A repository-level `zlib-tui` skill records the TUI rules and which tests to run per area; like `repo-readme`, it stays in `.agents/skills/` and is not shipped in the plugin (the sync script copies only `zlib` and `kindle`).

## Traps found the hard way

- **Docs can describe code that is gone, or never shipped.** Earlier, CLAUDE.md named symbols (`maxChallengeAttempts`, `cookiesMu`, …) that `git log -S` could not find in any commit; later, it kept describing a transport that had been deleted. Treat unfamiliar symbols in CLAUDE.md or this file as claims to verify with `grep`, not facts.
- **A repo-local `.env` silently overrides the saved session domain.** `.env` is loaded from the working directory and `~/.config/zlib/`, and `ZLIB_DOMAIN` there beats `session.json`. A command that unexpectedly targets the wrong mirror is usually this.
- **Status line script path.** `CLAUDE_CONFIG_DIR` is `D:\Claude\.claude`, but `bash ~/…` expands `~` from `$HOME` (`C:\Users\liyaoxin`), so a `~/.claude/statusline-command.sh` command ran a different file than the one being edited. Both `settings.json` files now use `bash D:/Claude/.claude/statusline-command.sh`, and the stray copy under `C:\Users\liyaoxin\.claude\` no longer exists. The script needs `jq` (`winget install jqlang.jq`).
- **Machine-wide `GOFLAGS=-mod=mod`** lets any `go build`/`go test`/`go vet` rewrite `go.mod`/`go.sum`. CI checks `go mod tidy` leaves `go.sum` unchanged, so look at `git diff go.mod go.sum` before committing.
