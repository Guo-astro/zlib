zlib tui puts everything in one full-screen app. Each step is also a command, and search, favorites, recommended, most-popular, history, profile, doctor, and config take --json. Pick one to see what it prints. zlib tui 把所有功能放进一个全屏界面。每一步也都是单独的命令，search、favorites、recommended、most-popular、history、profile、doctor、config 都支持 --json。点一条看它输出什么。

Hand it to your coding agent. 交给你的编码 agent。

zlib ships plugins for Claude Code and Codex. The agent calls the same binary you do, reads the same --json output, and installs zlib first if it is missing. Run zlib login yourself so your password stays out of the chat. zlib 自带 Claude Code 和 Codex 插件。Agent 调用的是同一个二进制，读的是同一份 --json 输出；没装 zlib 时会先自己装上。zlib login 请自己运行，密码不要发到对话里。

When the mirror fights back. 镜像站不让进的时候。

Most Z-Library web domains now sit behind DiamWall. Run doctor first: it checks all ten known domains without logging you in or touching your saved session, then lists the ones zlib can use. 现在大多数 Z-Library 网页域名都挂在 DiamWall 后面。先跑 doctor。它不用登录，也不动你已经存好的会话，把十个已知域名探一遍，只列出 zlib 能用的那些。

healthylisted; pass it to zlib login --domain会列出来，交给 zlib login --domain
challengeda JS challenge page; the API is unavailable there返回 JS 验证页，这里的 API 用不了
diamwall_blockedintercepted, so pick another被拦截了，换一个
redirect_loopredirects never reached the API重定向到不了 API
network_errorDNS, TLS, timeout, or reset. Try --proxyDNS、TLS、超时或连接重置，试试 --proxy
